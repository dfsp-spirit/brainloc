# Package index

## All functions

- [`brainparc()`](https://dfsp-spirit.github.io/brainloc/reference/brainparc.md)
  : Create a brain parcellation from custom data.

- [`brainparc_fs()`](https://dfsp-spirit.github.io/brainloc/reference/brainparc_fs.md)
  : Create a brain parcellation from a subject in a FreeSurfer recon-all
  output directory

- [`brainparc_neighbors()`](https://dfsp-spirit.github.io/brainloc/reference/brainparc_neighbors.md)
  : Compute adjacency of surface parcellation (annot) regions.

- [`cluster_location_details()`](https://dfsp-spirit.github.io/brainloc/reference/cluster_location_details.md)
  : Get details on cluster locations.

- [`cluster_peaks()`](https://dfsp-spirit.github.io/brainloc/reference/cluster_peaks.md)
  : Compute cluster peaks.

- [`cluster_region_overlap()`](https://dfsp-spirit.github.io/brainloc/reference/cluster_region_overlap.md)
  : Compute overlapping atlas regions for clusters.

- [`clusterinfo()`](https://dfsp-spirit.github.io/brainloc/reference/clusterinfo.md)
  : Create clusterinfo data structure from files or pre-loaded data.

- [`clusterinfo_from_thresholded_overlay()`](https://dfsp-spirit.github.io/brainloc/reference/clusterinfo_from_thresholded_overlay.md)
  : Create clusterinfo instance from thresholded per-vertex data
  overlays.

- [`coord_MNI152_to_talairach()`](https://dfsp-spirit.github.io/brainloc/reference/coord_MNI152_to_talairach.md)
  : Transform MNI152 coords to approximate Talairach space using Matthew
  Brett's approach.

- [`coord_MNI305_info()`](https://dfsp-spirit.github.io/brainloc/reference/coord_MNI305_info.md)
  : Get info on MNI305 surface coordinate in various coordinate systems.

- [`coord_MNI305_to_MNI152()`](https://dfsp-spirit.github.io/brainloc/reference/coord_MNI305_to_MNI152.md)
  : Transform MNI305 coords (FreeSurfer fsaverage surface) to MNI152
  coordinates.

- [`coord_closest_regions()`](https://dfsp-spirit.github.io/brainloc/reference/coord_closest_regions.md)
  : Find closest regions to coordinate using Euclidean or geodesic
  distance.

- [`coord_closest_vertex()`](https://dfsp-spirit.github.io/brainloc/reference/coord_closest_vertex.md)
  : Find closest surface vertex to a point, using Euclidean distance.

- [`fs_home()`](https://dfsp-spirit.github.io/brainloc/reference/fs_home.md)
  : Return FreeSurfer path.

- [`get_clusters()`](https://dfsp-spirit.github.io/brainloc/reference/get_clusters.md)
  : Get the clusters from a clusterinfo instance.

- [`get_subjects_dir()`](https://dfsp-spirit.github.io/brainloc/reference/get_subjects_dir.md)
  : Find subjects_dir or stop.

- [`get_surface()`](https://dfsp-spirit.github.io/brainloc/reference/get_surface.md)
  : Extract the surface hemilist from a brainparc.

- [`get_surface_coords()`](https://dfsp-spirit.github.io/brainloc/reference/get_surface_coords.md)
  : Extract the vertex coordinates from the brainparc surface.

- [`get_talairach_label()`](https://dfsp-spirit.github.io/brainloc/reference/get_talairach_label.md)
  :

  Retrieve Talairach labels for Talairach coordinates from
  `talairach.org` files.

- [`has_fs()`](https://dfsp-spirit.github.io/brainloc/reference/has_fs.md)
  : Check whether a FreeSurfer installation can be found on the system.

- [`hemilist()`](https://dfsp-spirit.github.io/brainloc/reference/hemilist.md)
  : Create hemilist.

- [`is.brainparc()`](https://dfsp-spirit.github.io/brainloc/reference/is.brainparc.md)
  : Check whether object is a brainparc instance.

- [`is.clusterinfo()`](https://dfsp-spirit.github.io/brainloc/reference/is.clusterinfo.md)
  : Check whether x is a clusterinfo instance.

- [`name_regions()`](https://dfsp-spirit.github.io/brainloc/reference/name_regions.md)
  : Get names of regions in labeled volume from color lookup table
  (colorLUT).

- [`print(`*`<brainparc>`*`)`](https://dfsp-spirit.github.io/brainloc/reference/print.brainparc.md)
  : Print description of a brainparc instance (S3).

- [`segmentation_centers()`](https://dfsp-spirit.github.io/brainloc/reference/segmentation_centers.md)
  : Find center of mass of regions in a brain volume segmentation.

- [`vertex_closest_regions()`](https://dfsp-spirit.github.io/brainloc/reference/vertex_closest_regions.md)
  : Find closest regions to vertex using Euclidean or geodesic distance.

- [`vertex_regions()`](https://dfsp-spirit.github.io/brainloc/reference/vertex_regions.md)
  : Find regions for vertices in all brainparc atlases.
