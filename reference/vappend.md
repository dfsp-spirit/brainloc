# Append to vector or NULL.

Append to vector or NULL.

## Usage

``` r
vappend(vec, val)
```

## Arguments

- vec:

  an existing vector or NULL

- val:

  the value to append.

## Value

the value itself if vec is `NULL`, the vec with the appended val
otherwise.

## Note

There almost certainly is a better way to do this, please open an issue
and let me know how if you know it.
