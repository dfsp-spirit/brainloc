# Get colors for `fs.annot` regions.

Get colors for `fs.annot` regions.

## Usage

``` r
region_colors(annot, region_names, na_color = "#FFFFFF")
```

## Arguments

- annot:

  full fs.annot instance

- region_names:

  vector of char strings, the query regions for which to get color
  strings

- na_color:

  color to assign to regions which were not found.

## Value

vector of hex color strings
