# Get info on MNI305 surface coordinate in various coordinate systems.

Get info on MNI305 surface coordinate in various coordinate systems.

## Usage

``` r
coord_MNI305_info(coords_mni305, ...)
```

## Arguments

- coords_mni305:

  nx3 matrix of coordinates, typically from fsaverage surface vertices.

- ...:

  Passed on to
  [`coord_MNI305_to_MNI152`](https://dfsp-spirit.github.io/brainloc/reference/coord_MNI305_to_MNI152.md).

## Value

named list with coordinate information (matrices)
