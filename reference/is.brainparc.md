# Check whether object is a brainparc instance.

Check whether object is a brainparc instance.

## Usage

``` r
is.brainparc(x)
```

## Arguments

- x:

  any \`R\` object

## Value

logical, `TRUE` if parameter `x` is a brainparc instance (that is, has
"brainparc" in its classes) and `FALSE` otherwise.
